How ClaimSight AI works

ClaimSight uses the inventory description and photographic evidence to identify each lost item, then researches current Australian replacement products and pricing. Every suggested valuation remains subject to assessor review before it reaches a report.

Advanced configuration

Set as deployment environment variables and applied on the next deploy: VALUATION_MODEL, MAX_SEARCHES_PER_ITEM and VALUATION_WORKERS. More searches improve accuracy on obscure items but increase cost faster than linearly.

Valuation basis

Depreciation is set per claim, not globally, because policies differ.

Indemnity settlement applies straight-line depreciation over each item's assessed effective life, adjusted for recorded condition and floored at 10% residual value. Replacement settlement pays the full new-for-old cost with no depreciation.

Switch basis from the valuation inspector on any claim. Per-item indemnity figures are retained either way, so the basis can be changed without re-valuing anything.
